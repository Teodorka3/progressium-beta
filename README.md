# Прогрессиум (Beta)

Бесплатная бета геймифицированного трекера прогресса для Windows.

## Скачать

**[Скачать Progressium Beta (Windows x64)](https://lichnyj-treker-progressa.vercel.app/downloads/Progressium-Beta-win-x64.zip)**

## Установка

1. Скачайте ZIP.
2. 2. Распакуйте.
   3. 3. Запустите `LevelingApp.exe`.
     
      4. Требуется Windows 10/11 и интернет для синхронизации. .NET отдельно устанавливать не нужно.
